# Community theme catalogue fixtures

These offline catalogue and `theme.json` snapshots come from [TnT-Studio-s/Hollycast-themes](https://github.com/TnT-Studio-s/Hollycast-themes) at commit `96e169558c9f9120b06f8dcd32e9534282a8f705` (2026-11-13), which publishes all five themes as version 1.0.0. Blue Hour’s manifest exercises the cinematic and themed DCnet support added by Hollycast commit `aeddc1441ac137ac497ae2ac69d85adc0260b175`.

The source repository and Blue Hour theme are GPL-2.0 licensed; `LICENSE` is copied verbatim from the pinned source. No theme ZIPs, artwork, or fonts are included here. Offline tests create placeholder image files and reuse a font already present in the Hollycast test data.

# QR Code generator

The unmodified C++ library from [Project Nayuki](https://github.com/nayuki/QR-Code-generator),
commit `bcfe1b018cec5f1f91b5705eca5bb4cdd34e9f8d`.

Used to display local phone VMU pairing addresses. The MIT license is included in
both source files. No network service is used to generate pairing codes.

# Disc Orbit

Original Hollycast layout, GPL-2.0-or-later. The approved generated mockup is a visual reference only; no generated game art is bundled. Disc faces use scraped physical media, then embedded Dreamcast labels or the library cover. Missing artwork uses a plain disc with the game title. The center uses miximage, screenshot, then the existing cover. All game text comes from the library.

The highlighted disc slowly spins around its spindle once it settles at the front (one turn every 24 seconds). The center miximage and metadata remain stationary.

Click a disc to select it, double-click to play, use Left/Right or the controller to rotate/confirm, or scroll the mouse wheel. Context menus retain favourites and per-game actions. The seven visible discs are a window onto the complete filtered library. Library Icon Size adjusts the disc size while the image and information retain their screen positions.

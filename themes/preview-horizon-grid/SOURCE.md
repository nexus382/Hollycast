# Hollycast preview layout

Original native Hollycast JSON layout by The Hollycast Authors, licensed under GPL-2.0-or-later. See the [GNU license text](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html).

This package implements a requested game-list mockup inspired by the [ES-DE theme catalog](https://gitlab.com/es-de/themes/themes-list/). It contains no copied ES-DE XML, fonts or images. Game media comes from the user's local library. The preview name identifies the requested visual reference, not an official port or endorsement. The `*` marks this version for review.

# Library theme verification — 31 October 2026

Revision under test: `0eb2d39c5` on `pocket-dimension-theme`, followed by the
uncommitted fixes described below. Eight bundled library themes, eleven layouts.

## Result

All eight themes were inspected in the running macOS app at wide and narrow
window sizes, and each theme launched an installed game successfully. Dedicated
portrait layouts in Demo Disc, Pocket Dimension and Warning! selected themselves
automatically in narrow windows. After the follow-up fix, 309 distinct automated
tests passed across the targeted suite and local-export check. One optional live
provider check was skipped and two live tests remained disabled.

Four functional issues found during this pass and its follow-up were fixed. This is a desktop functional
and visual pass, with the hardware and live-service qualifications below; it is
not an unrestricted claim that every platform and input device has been tested.

## Fixes verified

1. **Exit dialog in narrow windows:** Cancel extended outside the original modal.
   The shared dialog now wraps its message, clamps its width to the display, and
   stacks its actions when a horizontal row will not fit. Actual portrait checks
   confirmed all three actions visible, Cancel returns to the command menu, and
   Exit Without Saving returns to the library. Wide windows retain the row.
   The regression test exercises 320, 600 and 1400 px display widths.
2. **Unavailable artwork controls:** the shared renderer forced disabled alpha
   to 1 even during normal browsing, so missing-art buttons looked active. That
   override now applies only during a launch sequence. A rendered-alpha
   regression test checks both unavailable and available media; actual Pocket
   checks confirmed missing Mix/Screenshot controls dim correctly.
3. **Pocket Dimension Disc selector:** both layouts now opt into the existing
   shared `disc` source. It prefers provider disc artwork and can fall back to a
   label extracted from a Dreamcast ROM. Actual selection displayed the extracted
   Metal Slug 6 label. Themes that request only `physical` retain that behavior.
4. **Unrelated artwork downloads blocked one another:** the follow-up reproduced
   the intermittent queue failure 12 times in 100 runs. A slow image request held
   one of 64 striped locks; unrelated paths with the same hash slot then blocked
   behind it. Locks are now specific to each cache path for the scraper's batch.
   Duplicate requests and remembered unavailable results still share the same
   path state. A deliberately colliding regression failed three times before
   the fix. Afterward, that regression, the original queue test and the duplicate
   download test passed 100 repeats each. No timeout was increased.

An additional regression test covers populated → empty → repopulated results
across all eleven layouts at wide and narrow sizes. It checks that game metadata
clears and game actions cannot fire without a game. A fresh actual Horizon Grid
check also cleared the previous game's artwork/details and disabled Play after
a no-match search; an earlier suspicious capture was not reproduced.

  coverage passed; actual desktop keyboard paths were exercised.
- macOS automation exposes window chrome but not ImGui widgets in accessibility.
  Retina pointer coordinates were inconsistent and some targets returned
  `noWindowsAvailable`. Pointer selection was observed, but complete pointer
  activation, per-game context menus, long press, Resume and Start Fresh from
  those menus are not marked manually verified.
- The real four-entry library fits one Warning! wave. Partial last pages and
  crossing wave boundaries were verified by automated larger-library fixtures,
  not by adding dummy games to the user's library.
- Cached images demonstrate rendering, not a fresh authenticated ScreenScraper,
  TGDB or LaunchBox download for every media category. Provider mapping/queue
  fixtures passed; `LaunchBoxCacheTest.LiveProviderSmokeCheck` was skipped, and
  the two live ScreenScraper tests remained disabled.
- No other OS, mobile hardware, long-duration soak, or packaging/notarization
  compatibility pass was performed. The local linker warns that Homebrew SDL
  and PNG dependencies target a newer macOS than the project's minimum target.

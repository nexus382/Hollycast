Which download should I choose?

Choose Master for everyday use, or Dev to try the newest changes. Dev may have bugs. Pick the newest build in your chosen column.

  • Windows PC: Use Windows x64—the standalone MinGW build, matching Flycast's CI page.
  • Android phone or tablet: Choose the APK. If it comes in a ZIP, extract it first.
  • Xbox One or Series: Use the Xbox One download (UWP x64). Xbox Developer Mode is required.

Builds appear here once all six platform downloads are ready. Each build offers one download per platform. If a download is a ZIP, extract it first. No sign-in needed.

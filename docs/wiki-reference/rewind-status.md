# Hold-to-Rewind Gameplay History

Hold-to-rewind is under review. The proposed control steps backward through recent gameplay while you hold it and resumes when you release it. The proposal limits rewind to eligible offline sessions. Check the source for progress before choosing a build for this feature.

## Try rewind in a build that includes it

1. Use a build with Rewind enabled. Start an eligible offline game.
2. Open **Settings → Advanced → Rewind**, enable rewind, then set how much history to keep.
3. Play for several seconds, then hold your mapped **Rewind** input to go back through recent gameplay. Release it to continue from the new point.
4. Use **Commands → Step Back** for a single snapshot where available. Check the build's rewind restrictions if the option is missing or unavailable.

# Library startup and BIOS artwork

Configured games appear while metadata finishes loading. Covers are the default media for the Original icon and list views, while saved media choices are preserved. The BIOS entry has bundled cover, disc, and CD Rack spine artwork.

## Check startup and BIOS artwork

1. Open the standalone app with a game folder and Dreamcast BIOS already configured.
2. Open **Original** in the icon or list view to browse your library using the artwork type you selected.
3. Find **Dreamcast BIOS** in the **Original** library to see its bundled cover. Switch to **CD Rack** for the spine artwork.

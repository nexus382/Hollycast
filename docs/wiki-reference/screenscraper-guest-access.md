# ScreenScraper guest access

Guest artwork requests now use ScreenScraper's guest availability status, so a response without personal account fields is no longer treated as an account rejection. Personal sign-in checks and quota handling remain in place.

## Get artwork as a guest

1. Open **Settings → Library → Artwork Downloads** on an internet-connected standalone Hollycast build.
2. Select **ScreenScraper** as the **Artwork Provider**. Leave the personal account fields empty to use **Guest access**.
3. Make sure **Fetch Box Art** is enabled. Choose the media types in **Images to Download**, apply them, then select **Download Selected Media**.
4. Check the ready and unavailable counts and return to a library layout that displays your chosen art. A guest quota or unavailable title can still affect results.

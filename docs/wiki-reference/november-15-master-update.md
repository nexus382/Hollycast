# November 1–7 Changes Promoted to Master

This promotion adds theme browsing, previews, downloads, and installation, plus the **Download Themes** settings row. It also includes large-library memory, artwork, and save-scan improvements, configurable hover delay, Blue Hour theme support, and Android date display in the device time zone.

## Browse and install a theme

1. With an internet connection, open **Settings → Library → Library Themes → Download Themes**.
2. Pick a catalogue entry, review its screenshots, then choose **Download and install**. Wait for the installation message.
3. Choose **Use theme** on the installed entry and return to the library to see the new layout. In **Original** or **List**, you can adjust **Game Info Hover Delay** in **Settings → Library** and hover over a game to check the timing.

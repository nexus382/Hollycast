# Complete the UI translations and add Hindi support

Completes UI translations across 13 languages and cleans up English wording. Adds Hindi using Noto Sans Devanagari and HarfBuzz, with fixes for translated text sizing, clipping and language selection.

## Change the interface language

1. In the standalone app, open **Settings → General → App language → Interface language**.
2. Choose your language. For Hindi, select **हिन्दी**.
3. Open another settings tab and check that its labels use the selected language. Use **System default** if you want Hollycast to follow your device language.

# Download library themes

Open **Settings > Library > Download Themes** to browse previews and descriptions, then install a theme from the online catalogue. The **Artwork Downloads** section is expanded by default.

## Steps

1. With internet access, open **Settings > Library**, expand **Library Themes**, and select **Download Themes**. Confirm that **Artwork Downloads** is expanded on a fresh settings profile.
2. Browse the screenshots and descriptions, then select **Download and install** on a theme.
3. When installation finishes, select **Use theme** and return to the library to see the new appearance.

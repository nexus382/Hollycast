# Phone VMU Progress Sync

During a phone VMU mini-game, choose **Return to Dreamcast** to save progress back to Hollycast and reconnect the card; no manual file transfer is needed. The card is backed up before its first update, and retries avoid applying old progress again.

## Return a mini-game save to the Dreamcast

1. Open the live Phone VMU page from desktop Hollycast and select the card that holds your game. Choose **Play mini-game on this card**.
2. Play and use the mini-game's usual save or exit action. Keep the browser tab open and the host connected.
3. Choose **Return to Dreamcast** and wait for the sync confirmation. Resume the emulator if it is paused and the save is waiting.
4. In the Dreamcast game, use its standard VMU transfer or load screen. For *Chao Adventure*, jump onto the Transporter's red button in the garden and select what to bring back. See [the mating guide](phone-vmu-display-and-minigames.md#mate-two-adult-chao-and-bring-the-eggs-back) for two linked cards.

# Phone VMU Progress Sync

During a phone VMU mini-game, choose **Return to Dreamcast** to save progress back to Hollycast and reconnect the card; no manual file transfer is needed. The card is backed up before its first update, and retries avoid applying old progress again.

[Source pull request #74](https://github.com/nexus382/Hollycast/pull/74)

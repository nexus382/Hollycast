# Fix favourite star scaling in the library

Keeps favourite stars at their current size when library scaling reaches 200%, then scales them with covers below that setting. The star and its button scale together in All Games, Favourites and Continue Playing.

## Check the star at different library sizes

1. In the standard icon library, star a game. Save a state for the same game if you want to check it in **Continue Playing** as well.
2. In the library toolbar, open **Icon Size** and set it to **200%**. Check the star alongside the cover.
3. Lower **Icon Size** to shrink the covers and their stars in **All Games**, **Favourites**, and **Continue Playing**. Select the star to add or remove the game from Favourites.

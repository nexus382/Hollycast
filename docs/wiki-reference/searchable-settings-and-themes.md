# Settings panel and theme installs

Settings now has an icon navigation rail, page titles and descriptions, and search. Press **Ctrl+K** on Windows/Linux or **Cmd+K** on macOS to focus search; type a setting name and press Enter to open its page. The General page includes a setup-status banner, language and Dreamcast defaults, and folder shortcuts. Changes save automatically.

Newer catalogue themes can install with their updated layout fields. Carousel layouts fall back to the cover grid, and the toolbar setting "hidden" lets a theme draw its own controls.

## Find a setting or switch themes

1. Open **Settings**. Press **Ctrl+K** on Windows/Linux or **Cmd+K** on macOS to focus search, or select the search field.
2. Type the setting name and press **Enter** on the matching result. Check its page and description before changing it.
3. To try a theme, go to **Settings → Library → Library Themes → Download Themes**. Install a package, choose **Use theme**, and return to the library to see its layout.

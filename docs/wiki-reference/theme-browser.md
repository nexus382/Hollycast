# Add theme browser with downloads and installation

Open **Settings → Library** and find **Browse themes** or **Download Themes**, depending on your build. Search the catalog, preview a theme, and download it. Select the installed theme to apply it.

## Steps

1. With an internet connection, open **Settings > Library > Library Themes > Download Themes**.
2. Search by theme name or creator and inspect the listing's screenshots and description.
3. Select **Download and install**. When installation finishes, select **Use theme** and return to the library to see the new layout.

# Add Pocket Dimension, Demo Disc and Warning! with shared artwork support

Pocket Dimension, Demo Disc, and Warning! give the library different layouts. They share the artwork settings for TheGamesDB, ScreenScraper, and LaunchBox. TheGamesDB is the default and can supply artwork missing from your chosen provider.

## Choose a layout and download artwork

1. Open **Settings → Library → Library Themes → Library Layout** and choose **Pocket Dimension**, **Demo Disc**, or **Warning!**.
2. With an internet connection, open **Settings → Library → Artwork Downloads → Artwork Provider**. Choose **TheGamesDB**, **ScreenScraper**, or **LaunchBox**, then choose **Download All Media for All Themes** if you want to prepare every installed theme.
3. Return to the library and check that the new layout appears. Artwork for matched titles appears as downloads finish.

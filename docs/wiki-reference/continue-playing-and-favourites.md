# Add Continue Playing and favourites to the game library

Star a game to keep it under **Favourites**. **Continue Playing** gives you quick access to games with saves. Select **Resume** to load the latest state or **Start Fresh** to boot the game normally. These choices leave your auto-load preference as set.

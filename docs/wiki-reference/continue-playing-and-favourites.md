# Add Continue Playing and favourites to the game library

Star a game to keep it under **Favourites**. **Continue Playing** gives you quick access to games with saves. Select **Resume** to load the latest state or **Start Fresh** to boot the game normally. These choices leave your auto-load preference as set.

## Save a favourite and resume a game

1. In **All Games**, select the star on a game you have added to the library. Open **Favourites** and check that the game appears.
2. Launch the game and reach a recognizable point. Open the pause menu, choose **Save State**, and return to the library.
3. Open **Continue Playing** and choose **Resume** for that game. **Resume** loads the saved point. To boot the game normally on a later visit, choose **Start Fresh**.

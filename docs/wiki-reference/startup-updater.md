# Startup updates

Downloaded Master and Dev builds can check for updates at startup and show version details and changes since the installed build. Those builds can choose which channel to install; Google Play builds continue to use Play's update flow.

## Steps

1. On an internet-connected standalone desktop build that includes the updater, open **Help > Check for Updates**.
2. In **Hollycast Updates**, choose **Master** or **Dev** under **Update track** and select **Check now**. Compare **Current version** and **Newest version** when both are shown, and read the available change notes.
3. If you choose to install an available update, close any running game and select **Update and restart**. Reopen the update dialog after restart and confirm **Current version**. If you installed through Google Play, check for updates in Google Play.

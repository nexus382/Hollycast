# Add VMU transparency control

Adds a transparency slider beside VMU size, with live updates on Windows, macOS, Linux and Android. Fully transparent VMUs do not block input or reappear when the Android menu opens.

## Steps

1. Start a game that displays a VMU LCD and open **Settings > On Screen Display > In-Game Display**.
2. Enable **Show VMU In-Game** and, if the slider is hidden, enable **Move VMU**. Open **VMU Transparency**.
3. Compare **0%** and **100%** during gameplay. At **0%** the LCD is solid, and at **100%** it disappears and leaves the area available for input.

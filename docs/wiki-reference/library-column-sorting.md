# Sort the Original library list

In the Original list view, select a sortable heading—Product ID, Title, Region, Format, Time Played, Last Booted or Latest Save, Size, or Favourite—to change the order. Select it again to reverse the sort. Select it once more to restore the normal view order. Dates, times, and sizes use their actual values.

# Sort the Original library list

In the Original list view, select a sortable heading—Product ID, Title, Region, Format, Time Played, Last Booted or Latest Save, Size, or Favourite—to change the order. Select it again to reverse the sort. Select it once more to restore the normal view order. Dates, times, and sizes use their actual values.

## Sort the list

1. With several games in the library, choose **Original** under **Settings → Library → Library Themes → Library Layout** and **List** under **Library Display Style**.
2. Return to the library and select **Title**. Select it again to reverse the order, then a third time to return to the default order.
3. Try **Size** or **Time Played** on entries with different values to see them ordered by their numeric values.

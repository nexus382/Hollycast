# Fix Hollycast GitHub and Discord links

Updates the About page, Help menu, README, Linux package metadata and setup scripts to use the Hollycast repository and Discord invite. Report Bug opens the GitHub issue chooser. FreeBSD setup uses cmake-core, matching dev.

## Find support or report a bug

1. Use **Help → Report Bug** on desktop to open the GitHub issue chooser. You can also open the [issue chooser](https://github.com/nexus382/Hollycast/issues/new/choose) directly.
2. Include the game, full Hollycast build, platform, what you expected, and the steps that reproduce the problem.
3. Follow the project links in the repo's README for downloads, credits, and the community Discord.
